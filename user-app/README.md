This is the dedicated, mobile-responsive web application for patients within the **PsicoUJA** clinical psychology platform. Designed specifically for low-friction daily interaction on smartphones and tablets, it enables patients to perform Ecological Momentary Assessments (EMA), engage in real-time encrypted messaging with their assigned therapist, and receive instant push notifications.

---

## ✨ Key Features & Clinical Capabilities

- **📋 Ecological Momentary Assessments (EMA)**: Intuitive daily Likert-scale questionnaires (monitoring depression, anxiety, experiential avoidance, and value-consistent actions) scheduled dynamically by the backend.
- **💬 Real-Time Therapist Communication**: Direct secure chat channel connecting the patient with their therapist, with real-time updates and message status indicators.
- **🔔 Cross-Platform Push Notifications**: Powered by Firebase Cloud Messaging (FCM) and Web Push Service Workers to deliver alerts for assigned questionnaires, therapist messages, and check-in reminders even when the app is closed.
- **🔑 Zero-Friction Patient Auth**: Secure login via a unique Patient Code (generated by therapist in the main dashboard) and personal password without requiring complex public registration.
- **📱 Accessible Mobile Interface**: High-contrast, clean UI built with Radix UI accessibility primitives and responsive Tailwind CSS layout tailored for one-handed mobile use.

## 🚀 Installation & Quick Start

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   Copy `.env.example` to `.env.local` and specify your Firebase keys and backend API endpoint:
   ```bash
   cp .env.example .env.local
   ```
   *(Ensure `NEXT_PUBLIC_API_URL` points to `http://localhost:8001` during local development)*.

3. **Run Development Server**:
   ```bash
   npm run dev -- -p 3001
   ```
   *The Patient Application will be accessible at [http://localhost:3001](http://localhost:3001).*

For a detailed step-by-step setup guide, see [INSTALL.md](./INSTALL.md).
